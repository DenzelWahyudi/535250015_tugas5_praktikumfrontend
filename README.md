# Tugas 5 Praktikum Pemrograman Front-End

- **NIM**: 535250015
- **Topik**: Landing Page Vendor MBG (Makan Bergizi Gratis) - PT UNTAR
- **Teknologi**: Next.js (App Router), TypeScript, React Bootstrap

## Deskripsi
Tugas ini mengimplementasikan landing page untuk PT UNTAR yang bertindak sebagai vendor penyedia makanan dalam program Makan Bergizi Gratis (MBG). Halaman ini menampilkan:
- Navigation bar yang responsif dengan link menu
- Hero section menggunakan Carousel dengan highlight program
- Daftar menu harian (Senin - Jumat) beserta rincian gizi seimbang
- Kartu standar nutrisi dan higienis makanan
- Footer informasi kontak dan lokasi

## Cara Menjalankan
1. Pastikan Node.js sudah terpasang.
2. Install dependency:
   ```bash
   npm install
   ```
3. Jalankan aplikasi di environment development:
   ```bash
   npm run dev
   ```
4. Buka browser dan akses [http://localhost:3000](http://localhost:3000).
